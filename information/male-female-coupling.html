Male → Female Stat Coupling — Architecture

How (and how little) the playable male character's stats actually influence a female NPC's stats, emotions, and reactions. The short version: male stats almost never reach female emotion code as numbers. There are exactly three coupling mechanisms — one true direct stat read (attraction → consent), one physical bridge (penis dimensions → bone stretch → pleasure/pain), and one detection threshold — plus a large set of things that look coupled but aren't. All paths are under SMANew/ExportedProject/Assets/Scripts/ unless noted.

1The three coupling paths

Cross-referencing the male stat system against the female reaction system: the male's stat holder (AlteradoresDeCharacterMasculino) is referenced by zero female / emotion / stimulus / reactor files — it writes only into male-owned controllers. 2Path ① — attraction → consent / favorability DIRECT STAT READ

The weighting function (ValorDeTrait, lines 104-109) is the crux — each male attribute only counts to the degree this female's personality likes that trait:

private float ValorDeTrait(float attributo, TraitHumano trait, float maxConcent){
    float a = (attributo / 100f).InPow(2f);                                  // male attribute, squared
    float w = maxConcent * m_personalidad.GetTraitScore(trait).GetWeigthDeScore(); // HER taste weight
    return a * w;
}

3Path ② — penetration → Placer / Dolor / Rage PHYSICAL BRIDGE

Penis size / girth / length never appear as numbers in female emotion code. Instead the alteradores drive the male Penetrador's physical dimensions, those physically stretch the female hole's bone chain, and the female reads her own stretch state. The causal chain:

So girth (worldMaxWidth) drives the width stimulus branch and length (worldLength) drives the depth branch — but only by physically producing more stretch. There is no if (penisGirth > X) anywhere in female code.

4Path ③ — penis length as a detection threshold GATE ONLY

Several reactors use pene.worldLength purely as a squared radius to decide whether the female can see or reach the penis. A bigger penis is noticed/reachable from farther away — but the reaction it triggers has a fixed magnitude; size does not scale the response.
